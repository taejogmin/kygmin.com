> **이 노트의 범위:** 교재 부록 「핵심공식」 Chapter 01 중 12~20번(옵션 포지션별 손익 → 내재가치·시간가치 → 이항모형 → 블랙-숄즈 → 합성전략)을 정리한 것이다. 옵션 계산 문제는 **① 만기 수취액 Max(…, 0) 구하기 ② 프리미엄을 매수는 빼고 매도는 더하기** 두 단계로 끝난다.

## 1. 옵션 포지션별 만기 손익 🔴

네 포지션의 손익식은 "수취액에서 프리미엄을 조정"한 것이고, 매도는 매수의 부호만 뒤집은 것이다(제로섬).

| 포지션 | 만기 손익(프리미엄 고려) | 전망 | 최대이익 | 최대손실 |
|---|---|---|---|---|
| **콜 매수** | Max(S_T − K, 0) − c | 가치 **상승**을 확신 | 무제한 | c |
| **콜 매도** | −Max(S_T − K, 0) + c | 강세를 보이지 않을 것 + 변동성 축소 | c | 무제한 |
| **풋 매수** | Max(K − S_T, 0) − p | **약세** 예상 | K − p | p |
| **풋 매도** | −Max(K − S_T, 0) + p | 약세를 보이지 않을 것 + 변동성 축소 | p | K − p |

### 1.1 콜옵션

$$
\pi_{\text{콜 매수}}=\max(S_T-K,\,0)-c
\qquad
\pi_{\text{콜 매도}}=-\max(S_T-K,\,0)+c
$$

| 만기 상황 | 권리 행사 여부 | 수취액(내재가치) |
|---|---|---|
| S_T > K | 권리 행사 | S_T − K |
| S_T < K | 권리 포기 | 0 |

- 콜 매도자의 손익은 콜 매수자가 권리를 행사하는지에 따라 결정된다.

### 1.2 풋옵션

$$
\pi_{\text{풋 매수}}=\max(K-S_T,\,0)-p
\qquad
\pi_{\text{풋 매도}}=-\max(K-S_T,\,0)+p
$$

| 만기 상황 | 권리 행사 여부 | 수취액(내재가치) |
|---|---|---|
| S_T > K | 권리행사 포기 | 0 |
| S_T < K | 권리행사 | K − S_T |

### 1.3 손익분기점

- **콜옵션 매수자(매도자) 손익분기점 = 행사가격 + 콜 프리미엄**
- 풋옵션 매수자(매도자) 손익분기점 = 행사가격 − 풋 프리미엄
- 매수자와 매도자의 손익분기점은 같다(한쪽의 이익이 다른 쪽의 손실).

> **함정:** "권리를 행사했다 = 이익"이 아니다. K < S_T < K + c 구간에서는 콜을 행사하지만 프리미엄을 다 회수하지 못해 손실이다.

> **KOSPI200옵션 금액 환산:** 포인트 손익 × 250,000원 × 계약수.

## 2. 내재가치와 시간가치 🔴

**옵션가격(프리미엄) = 내재가치 + 시간가치**

### 2.1 내재가치 (행사가치 = 본질가치, Intrinsic Value)

$$
\text{콜 내재가치}=\max(S-K,\,0)
\qquad
\text{풋 내재가치}=\max(K-S,\,0)
$$

- 지금 당장 행사했을 때 얻는 가치. **0보다 작을 수 없다.**
- 내가격(ITM): 내재가치 > 0 — 콜은 S > K, 풋은 S < K
- 등가격(ATM): S = K / 외가격(OTM): 내재가치 = 0

### 2.2 시간가치 (Extrinsic Value)

$$
\text{시간가치}=\text{옵션가격}-\text{내재가치}\;(\ge 0)
$$

- 콜 시간가치 = 프리미엄 − (기초자산가격 − 행사가격)
- 풋 시간가치 = 프리미엄 − (행사가격 − 기초자산가격)
- 괄호 안이 음수면 0으로 놓는다 → 외가격·등가격 옵션은 **프리미엄 전부가 시간가치**
- 만기에는 시간가치가 0이 되어 옵션가격 = 내재가치

> **함정:** 외가격 콜(S = 95, K = 100, 프리미엄 2)의 시간가치를 2 − (95 − 100) = 7로 계산하는 것. 내재가치는 −5가 아니라 0이므로 시간가치는 2다.

## 3. 이항모형 🟡

**1기간 이항분포모형의 콜옵션 가격**

$$
C=\left[P\times C_u+(1-P)\times C_d\right]\times e^{-rt}
\qquad
P=\frac{r+d}{u+d}
$$

- C_u: 주가 상승 시 콜 가치, C_d: 주가 하락 시 콜 가치
- P: **위험중립확률(헤지확률)** — 실제 상승확률이 아니다.
- u: 상승률, d: 하락률(크기), r: 무위험이자율. 조건: **상승비율(u) > 무위험이자율**
- 같은 식의 다른 표기: P = (1 + r − 하락배수) ÷ (상승배수 − 하락배수). 예) 100 → 120 또는 90, r = 5% → (0.05 + 0.10)/(0.20 + 0.10) = (1.05 − 0.9)/(1.2 − 0.9) = 0.5
- 풋옵션도 같은 P로 [P × P_u + (1 − P) × P_d]를 할인한다.

> **할인 방법:** 교재 식은 연속복리 e^(−rt)이다. 문제에서 "(1 + r)로 할인"이라고 주면 그대로 따른다. 이 허브의 문제는 할인 방법을 지문에 적어 두었다.

## 4. 블랙-숄즈 모형 🟡

$$
c=S\cdot N(d_1)-Ke^{-rT}\cdot N(d_2)
\qquad
p=Ke^{-rT}\cdot N(-d_2)-S\cdot N(-d_1)
$$

$$
d_1=\frac{\ln(S/K)+(r+\sigma^2/2)T}{\sigma\sqrt{T}},
\qquad
d_2=d_1-\sigma\sqrt{T}
$$

| 기호 | 의미 |
|---|---|
| **N(d₁)** | 콜옵션의 **델타** — 기초주식 가격변화에 대한 콜 가격변화. 무위험 포트폴리오를 만들기 위해 **매도한 콜 1계약당 매수해야 할 주식수** |
| **N(d₂)** | 만기에 주가가 행사가격보다 클 가능성 = **콜옵션이 행사될 가능성** |
| **−N(−d₁)** | 풋옵션의 **델타** (= N(d₁) − 1) |

- 콜 델타는 0 ~ 1, 풋 델타는 −1 ~ 0
- 입력변수: 주가(S), 행사가격(K), 무위험이자율(r), 잔존기간(T), 변동성(σ). **주가의 기대수익률은 들어가지 않는다.**

> **함정:** N(d₁)과 N(d₂)의 의미를 바꿔 낸다. **d₁ = 델타(헤지비율), d₂ = 행사 확률.**

## 5. 합성전략 손익구조 🔴

### 5.1 스트래들 매수

같은 행사가격의 콜과 풋을 **동시에 매수**.

- **손익분기점 = 행사가격 ± 프리미엄(콜 + 풋 합계)**
- 최대손실 = 프리미엄 합계(S_T = K일 때), 이익은 양쪽으로 열려 있다.
- 방향은 모르지만 **변동성 확대**를 예상할 때.

### 5.2 스트랭글 매수

낮은 행사가격(K₁)의 풋과 높은 행사가격(K₂)의 콜을 동시에 매수.

- **손익분기점 = K₁ − 프리미엄, K₂ + 프리미엄** (프리미엄은 합계)
- 최대손실 = 프리미엄 합계(K₁ ≤ S_T ≤ K₂ 구간 전체)
- 스트래들보다 프리미엄이 싸지만 손익분기점 사이가 더 넓다.

### 5.3 콜 수직 강세 스프레드

낮은 행사가격(K₁) 콜 **매수** + 높은 행사가격(K₂) 콜 **매도**. 프리미엄 차이 = 지불한 프리미엄 − 받은 프리미엄(순지불액).

- **최대손실 = 프리미엄 차이**
- **손익분기점 = K₁ + 프리미엄 차이**
- **최대이익 = (K₂ − K₁) − 프리미엄 차이**

> **교재 표기 주의:** 교재 683쪽에는 최대이익이 "행사가격(K₂ − K₁) **+** 프리미엄 차이"로 인쇄돼 있다. 최대손실과 손익분기점에서 쓴 프리미엄 차이(순지불액, 양수)를 그대로 쓰면 최대이익은 (K₂ − K₁)에서 그 금액을 **빼야** 한다(행사가격 차이만큼 벌고, 낸 프리미엄만큼 깎인다). 이 노트와 문제는 뺀 값 기준이다. 본문 장에서 프리미엄 차이를 "받은 − 지불"(음수)로 정의했다면 같은 뜻이다.

## 7. 옵션가격 결정요인 🔴

**옵션가격(프리미엄) = 내재가치(기초자산, 행사가격) + 시간가치(변동성, 잔존기간, 금리)**

| 요인이 상승하면 | 콜가격 | 풋가격 |
|---|---|---|
| 기초자산가격 | + | − |
| 행사가격 | − | + |
| **변동성** | **+** | **+** |
| **잔존기간** | **+** | **+** |
| 금리 | + | − |
| 배당 | − | + |

- 변동성과 잔존기간만 콜·풋 **둘 다 (+)**, 나머지 넷은 콜과 풋이 반대다.
- 내가격(ITM): 콜은 기초자산(S) > 행사가격, 풋은 기초자산(S) < 행사가격
- **시간가치는 ATM 옵션이 가장 크다.**
- **ATM 옵션은 콜가격 > 풋가격**

## 8. 현물옵션과 선물옵션 🟡

- 현물옵션: 기초자산이 현물인 옵션
- 선물옵션: 권리행사 시 **선물포지션**을 갖게 된다.

| 구분 | 포지션 | 권리행사 시 |
|---|---|---|
| 콜옵션 | 매수자 | 행사가격으로 선물 **매수**포지션 |
| 콜옵션 | 매도자 | 행사가격으로 선물 **매도**포지션 |
| 풋옵션 | 매수자 | 행사가격으로 선물 **매도**포지션 |
| 풋옵션 | 매도자 | 행사가격으로 선물 **매수**포지션 |

## 9. 옵션가격의 범위와 풋-콜 패리티 🔴

### 9.1 유럽형 옵션가격의 범위

$$
0<S-Ke^{-rt}<c<S
\qquad\qquad
0<Ke^{-rt}-S<p<Ke^{-rt}
$$

- 콜의 상한은 **기초자산가격**, 풋의 상한은 **행사가격의 현재가치**

### 9.2 풋-콜 패리티 (Put-Call Parity)

동일한 만기, 동일한 행사가격의 콜가격과 풋가격 사이의 균형식.

$$
S+p=c+Ke^{-rt}
$$

- **주식 매수 + 풋 매수 = 콜 매수 + 채권 매수**
- 풋 매수 + 콜 매도 = 채권 매수 + 주식 매도
- 계산: c = S + p − Ke^(−rt), p = c + Ke^(−rt) − S

## 10. 옵션을 이용한 헤지거래 🔴

### 10.1 방어적 풋 (Protective put)

**보유(매수) 포지션 + 풋옵션 매수**

- 주식보유자 + 풋 매수 / 금리상승위험자 + 풋 매수 / 수출상(외화보유자) + 풋 매수 / 상품보유(생산자) + 풋 매수
- 특징: **손실 제한 / 이익 무제한**, **콜 매수포지션과 동일한 손익구조**, 일종의 **보험전략**

### 10.2 커버드 콜 (Covered call)

**주식보유자 + 콜 매도**

- **풋 매도와 같은 손익구조**, 프리미엄 수취

> **함정:** 방어적 풋 = 콜 **매수** 구조, 커버드 콜 = 풋 **매도** 구조. 풋-콜 패리티에서 나온다(주식 + 풋 = 콜 + 채권, 주식 − 콜 = 채권 − 풋).

## 11. 합성포지션과 옵션 차익거래 🔴

### 11.1 합성포지션

| 합성포지션 | 구성 |
|---|---|
| 합성 기준물 **매수** (+S) | 콜 **매수** (+C) + 풋 **매도** (−P) |
| 합성 기준물 **매도** (−S) | 콜 **매도** (−C) + 풋 **매수** (+P) |
| 합성 풋 **매수** (+P) | 콜 매수 (+C) + 기준물 **매도** (−S) |
| 합성 풋 **매도** (−P) | 콜 매도 (−C) + 기준물 **매수** (+S) |

### 11.2 기초자산과 옵션을 이용한 차익거래

| 거래 | 조건 | 상황 | 포지션 |
|---|---|---|---|
| **컨버전** (conversion) | S + p < c + X/(1 + r) | **콜옵션 고평가** | 합성기준물 **매도**(콜 매도 + 풋 매수) + 현물 **매수** |
| **리버설** (reversal) | S + p > c + X/(1 + r) | **풋옵션 고평가** | 합성기준물 **매수**(콜 매수 + 풋 매도) + 현물 **매도** |

- 고평가된 옵션을 **판다**고 기억한다: 콜 고평가 → 콜 매도가 들어간 컨버전.

### 11.3 옵션과 옵션을 이용한 차익거래 — 박스거래

- 크레딧 박스, 데빗 박스

## 12. 옵션 민감도 🔴

| 민감도 | 정의 | 특징 |
|---|---|---|
| **델타** | 옵션가격변화 / 기초자산가격 변화 | 0 < 콜델타 < 1, −1 < 풋델타 < 0. **헤지비율은 델타의 역수** |
| **감마** | **델타변화** / 기초자산가격 변화 | ATM이 가장 크다. **근월물 > 원월물** |
| **베가** | 옵션가격변화 / 변동성 변화 | ATM이 가장 크다. **근월물 < 원월물** |
| **세타** | 옵션가격변화 / 시간 변화 | ATM이 가장 크다. **근월물 > 원월물** |
| **로** | 옵션가격변화 / 금리 변화 | |

- 감마·베가·세타 모두 **ATM에서 최대**.
- 근월물이 더 큰 것은 감마·세타, **베가만 원월물이 더 크다.**

## 13. 옵션거래의 이해와 결제방식 🔴

**옵션거래:** 계약시점에 옵션매수자가 옵션매도자에게 **프리미엄**(옵션가격)을 지불하고, 그 대가로 기초자산을 **행사가격**으로 만기(또는 만기 이전)에 살 수 있는 권리(**콜**)나 팔 수 있는 권리(**풋**)를 갖는 거래.

| 용어 | 뜻 |
|---|---|
| 기초자산(underlying asset) | 주식, 채권, 통화, 상품 등 |
| 만기일(expiration date) | 약정된 기간 |
| 행사가격(strike price) | 약정된 가격 |
| 콜옵션 / 풋옵션 | 살 수 있는 권리 / 팔 수 있는 권리 |
| 프리미엄(옵션가격) | 권리를 사고파는 대가 |

### 현물옵션의 권리행사 결과

| 구분 | | 인수도결제 | 현금결제 |
|---|---|---|---|
| 콜옵션 | 매수자 | 기초자산을 **인도받고** 행사가격을 지불 | (기초자산가격 − 행사가격)을 수취 |
| 콜옵션 | 매도자 | 기초자산을 행사가격에 **매도(인도)할 의무** | 차액 지급 |
| 풋옵션 | 매수자 | 기초자산을 **인도하고** 행사가격을 수취 | (행사가격 − 기초자산가격)을 수취 |
| 풋옵션 | 매도자 | 기초자산을 행사가격에 **매수(인수)할 의무** | 차액 지급 |

- 매도자는 항상 **매수자의 반대**다. 콜 매수자가 "살" 권리를 쓰면 콜 매도자는 "팔아야" 하고, 풋 매수자가 "팔" 권리를 쓰면 풋 매도자는 "사야" 한다.
- 계약시점에 옵션 매도자는 의무를 지는 대신 **프리미엄을 받는다.**
- 콜 매수자는 기초자산가격이 오를수록, 풋 매수자는 내릴수록 권리행사 가능성이 커진다.

> **함정: 매수 ↔ 매도 한 단어 바꿔치기.** "콜옵션 매도자는 … 매수해야 한다"처럼 문장 구조는 그대로 두고 동사 하나만 뒤집는다. 콜 = 사는 권리 → 매도자는 **판다**, 풋 = 파는 권리 → 매도자는 **산다**.
